資本がより滑らかに循環する、AI × JPYC エコシステム。 AI エージェントが日本円ステーブルコインで、データ API を 1 回ずつ買う。 口座も契約もいらない。HTTP 402 と署名ひとつで、支払いが完了する。

Scroll to discover our process
  1. 01402 で価格がわかる

    有料の API を呼ぶと、HTTP 402 で価格（JPYC）と支払い条件が返ります。事前の登録も API キーもいりません。

  2. 02署名だけで支払う

    エージェントは EIP-3009 の署名を付けて呼び直すだけ。ガス代は不要で、データが届いたときだけ JPYC が動きます。

  3. 03届いたときだけ請求

    上流のデータを取れたときだけ settle。失敗したら署名は使われず、JPYC は動きません。

  4. 04数秒で受け取る

    Polygon で settle し、数秒でデータが返ります。
